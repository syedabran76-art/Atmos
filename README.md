ATMOS 🌤️

Weather, Reimagined.

ATMOS is a modern Android weather application developed by Naro Studios. It brings essential weather information together in a clean, intuitive interface designed for everyday use.

✨ Features

- 🌡️ Current weather conditions
- 📍 Location-based weather information
- 🔎 Manual city search
- 🌤️ Hourly weather forecasts
- 📅 7-day weather forecasts
- 🌡️ Celsius and Fahrenheit support
- 🎨 Custom ATMOS branding and interface

🛠️ Built With

- Language: Kotlin
- UI: Jetpack Compose
- Design: Material 3
- Weather Data: Open-Meteo API
- Location: Google Play Services Location
- Build System: Gradle
- Platform: Android

🚀 Building the Project

1. Clone the repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Build the Android application.

The project uses Gradle and GitHub Actions for automated builds.

🌐 Weather Data

ATMOS uses the "Open-Meteo API" (https://open-meteo.com/) for weather forecasts and geocoding.

Weather data is provided by Open-Meteo and is subject to its terms and attribution requirements.
